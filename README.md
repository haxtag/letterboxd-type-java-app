# Letterboxd-inspired desktop app

A team-built Java desktop application inspired by Letterboxd. It brings together films, series, episodes, user accounts, lists, and reviews.

## Requirements

- Java 25
- Eclipse IDE for Java development

## Run

Import this repository into Eclipse as an existing Java project. Open `src/graphique/ApplicationMedias.java` and run it as a Java Application.

The repository also contains tests under `src/tests`.
